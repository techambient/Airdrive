# Ambient Airdrive FTP
A next gen high speed (100 MBps+) wireless file transfer protocol from phone to laptop / tablet. 

[![License](https://img.shields.io/github/license/techambient/Airdrive?style=for-the-badge)](LICENSE)
[![Platform](https://img.shields.io/badge/Android-10%2B-34A853?style=for-the-badge)]()
[![Material 3](https://img.shields.io/badge/Material%203-Expressive-4285F4?style=for-the-badge)]()

<div align="left">

## 📖 Features

* Ultra-High Speed
* Seamless Wireless Transfer
* Stable and quick connection
* Easy to setup
* Lightweight, ~18MB only!
* Fast Speed
* Zero Ads & Zero Tracking
* 100% Unlimited free usage

## ⚠️ Requirements

* Android 10.0+
